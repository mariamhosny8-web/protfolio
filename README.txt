Mariam Hosny Portfolio

1. Extract the ZIP folder.
2. Open index.html in your browser.
3. Your profile photo is included in images/profile.jpg.
4. Four custom project preview illustrations are included in the images folder and displayed in the Projects section.
5. The Connect Me button scrolls to contact details: WhatsApp/phone, email, location, LinkedIn and GitHub.
6. Download CV downloads Mariam_Hosny_CV.pdf.

The project previews are designed illustrative previews of each project, not actual screenshots captured from the running projects. Replace them with real screenshots whenever you have them.
